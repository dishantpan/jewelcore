# JewelCore

JewelCore is a jewellery retail ERP and management platform built with Java, Spring Boot, MySQL, and React.

## Status

- Task 1: Spring Boot backend foundation completed
- GitHub repository initialized

## Current backend endpoint

- `GET /api/v1/health`

## Project goals

- Jewellery inventory with unique QR per item
- Role-based access for owner and salesperson
- Billing and invoice generation
- Customer history
- GST-ready reporting
- Returns and exchanges
- Clean, modular architecture

## Tech stack

- Java 21
- Spring Boot
- Spring Web
- MySQL
- React (planned)

## Notes

This project is being developed in small, tested tasks so each module can be verified before moving ahead.
